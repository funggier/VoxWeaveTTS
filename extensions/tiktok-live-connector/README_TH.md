# VoxWeaveTTS — TikTok LIVE (Extension)

ส่วนเสริม Chrome Manifest V3 v0.2.5 แบบติดตั้งเอง สำหรับส่งเฉพาะข้อความคอมเมนต์ใหม่จาก **แท็บ TikTok LIVE ที่ผู้ใช้เลือก** ไปยัง VoxWeaveTTS ผ่าน `127.0.0.1` โดยไม่ใช้ CDP หรือเปิด Browser อัตโนมัติ **ไม่ส่ง Gift/Follow/Like/Share/Join เข้าคิว TTS**

รุ่น v0.2.5 รองรับการอ่านอีโมจิและชื่ออีโมจิจาก `alt` ของรูปภายในคอมเมนต์ เพื่อให้ตั้งคำอ่านในโปรแกรมได้แบบเดียวกับโหมด Live อื่น โดยยังไม่รองรับการอ่าน Gift

## ติดตั้ง

1. Chrome → `chrome://extensions`
2. เปิด Developer mode → Load unpacked
3. เลือกโฟลเดอร์ `extensions/tiktok-live-connector` นี้
4. เปิดแท็บ `https://www.tiktok.com/@username/live` ที่คุณมีสิทธิ์เข้าถึง
5. ใน VoxWeaveTTS Tab **TikTok LIVE (Extension)** กรอก URL เดียวกันแล้วกด **สร้างรหัสจับคู่**
6. คลิกไอคอนส่วนเสริมในแท็บ LIVE → Port `8765` → วางรหัส → **เชื่อมต่อแท็บนี้**
7. หยุดโดยกดปุ่มหยุดที่ส่วนเสริมหรือใน VoxWeaveTTS

**หลังแก้ไข/อัปเดตส่วนเสริม:** เปิด `chrome://extensions` กด Reload ที่ส่วนเสริม **แล้วต้องรีเฟรชแท็บ TikTok LIVE ด้วย** เพื่อยกเลิก Content Script รุ่นเก่า จากนั้นจับคู่ใหม่ด้วยรหัสใหม่ รุ่น **0.2.3** ปรับตัวอ่าน Gift ให้รับจาก System/Notice และแถวทั่วไปที่ขึ้นว่า `sent ... × จำนวน` ก่อนการตรวจแชท พร้อมย้ายตัวเลือกอ่านเสียงและคำนำหน้าชื่อไปไว้ในเมนูรวมของ VoxWeaveTTS; รุ่น **0.2.2** แก้กรณีป้ายอันดับ `No. 2` ต่อท้ายชื่อผู้ส่งแล้วถูกอ่านเป็นคอมเมนต์ โดยเลือกข้อความจาก DOM เฉพาะส่วนข้อความก่อนใช้ข้อความรวมของแถว; รุ่น **0.2.1** เพิ่มการอ่านคอมเมนต์จากท้ายแถวที่มีจำนวนป้ายไม่เท่ากัน และปรับ DOM MutationObserver ให้รับข้อความแม้หน้าไม่อยู่ในโฟกัสโดยไม่รอ Background Timer พร้อมสถานะความสดของ DOM (ยังไม่รับประกันกรณี TikTok หยุดอัปเดต DOM เอง); รุ่น **0.2.0** เพิ่มการแยกชื่อผู้ส่งจากป้าย/เลเวล/ยศ และการส่ง Gift Event แบบแยกประเภทเมื่อพบข้อมูลบนหน้า LIVE พร้อมตั้งค่าให้อ่านหรือไม่อ่านแต่ละประเภทใน VoxWeaveTTS; รุ่น 0.1.2 เพิ่มการหยุด `MutationObserver` และ Timer เมื่อ Chrome แจ้ง `Extension context invalidated`; รุ่น 0.1.1 เพิ่มตัวอ่าน DOM และสถานะวินิจฉัยเป็นจำนวน

ถ้าเปิด Chrome Incognito ให้เปิด Allow in Incognito ของส่วนเสริมเองในหน้า Details ส่วนเสริมไม่ต้องการข้อมูลล็อกอินหรือคุกกี้จากเว็บไซต์

**ข้อจำกัด:** ผู้ใช้ยืนยันว่า Extension รับคอมเมนต์ LIVE จริงได้แล้ว แต่การแก้ป้าย `No. 2` รุ่นใหม่ยังทดสอบด้วย DOM จำลอง และต้องยืนยันกับ LIVE อีกครั้ง TikTok อาจจำกัดหรือห้ามการดึงข้อมูลอัตโนมัติหากไม่ได้รับอนุญาต ส่วนเสริมไม่ใช่เครื่องมือที่ TikTok อนุมัติ
