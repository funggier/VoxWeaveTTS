# TikTok LIVE (Extension) — คู่มือ Source Project v0.2.5

**หมายเหตุ:** ฟีเจอร์อีโมจิของ TikTok เพิ่มใน Source Project หลัง Release v0.5.1; ไฟล์ Portable v0.5.1 ที่เผยแพร่ก่อนหน้านั้นยังมี Extension v0.2.4 และต้องใช้โค้ดรุ่นใหม่จึงเห็นตัวเลือกนี้

**โหมดนี้รับเฉพาะข้อความคอมเมนต์จาก TikTok LIVE เท่านั้น** ไม่รองรับการอ่านข้อความแจ้งเตือนของขวัญ (Gift), Follow, Share, Join หรือ Like และไม่มีตัวเลือกเปิดการอ่าน Gift อีกแล้ว

## หลักการทำงาน

- ผู้ใช้เปิดหน้า TikTok LIVE ใน Google Chrome ปกติเอง และเลือกแท็บที่จะเชื่อมต่อ
- Extension (Manifest V3) ใช้สิทธิ์ `activeTab` เมื่อผู้ใช้กดเชื่อมต่อ ไม่เปิด Chrome ใหม่ ไม่อ่าน Cookies/รหัสผ่าน ไม่ทำงานด้วย CDP และไม่เข้าไปล็อกอินแทนผู้ใช้
- ส่วนเสริมอ่าน DOM ของ **คอมเมนต์ใหม่** เท่านั้น ข้ามรายการที่แสดงก่อนเริ่มรับข้อความ
- ส่งข้อมูลผ่าน `http://127.0.0.1:<port>` ไปยังโปรแกรม โดยต้องใช้รหัสจับคู่ชั่วคราวและ Session Token ที่ผูกกับไลฟ์/ส่วนเสริม
- คอมเมนต์ผ่านฟิลเตอร์ คิว TTS และ OBS Subtitle เดิม ชื่อผู้ชมจะแยกจากเนื้อหาคอมเมนต์และป้ายอันดับ/เลเวล

## ติดตั้งและเริ่มใช้งาน

1. แตก `VoxWeaveTTS-v0.5.0-portable.zip` ให้ครบทั้งโฟลเดอร์ หรือแตก ZIP ส่วนเสริมแยก `VoxWeaveTTS-TikTok-Extension-v0.2.4.zip`
2. เปิด Chrome ไปที่ `chrome://extensions` เปิด Developer mode แล้วกด **Load unpacked**
3. เลือกโฟลเดอร์ `extensions/tiktok-live-connector` (ต้องมีไฟล์ `manifest.json` อยู่ในโฟลเดอร์นั้น)
4. เปิดแท็บ `https://www.tiktok.com/@username/live` ที่สามารถเห็นข้อความคอมเมนต์
5. เปิด VoxWeaveTTS ไปที่แท็บ **TikTok LIVE (Extension)** กรอกชื่อช่องหรือ URL ให้ตรงแท็บ LIVE แล้วกด **สร้างรหัสจับคู่**
6. กลับไปแท็บ TikTok คลิกไอคอน Extension, ใส่ Port (ปกติ `8765`) และรหัสจับคู่ แล้วกดเชื่อมต่อ
7. เปิดหัวข้อ **กำหนดการอ่านข้อความและข้อมูลพิเศษ** เพื่อปรับ **อ่านข้อความใหม่อัตโนมัติ**, **อ่านชื่อผู้ส่งก่อนข้อความ**, **คำนำหน้าชื่อผู้ส่ง**, **คำเชื่อมหลังชื่อผู้ส่ง** และ **อ่านข้อความแชท**
8. หลังอัปเดต Extension ทุกครั้ง ให้กด Reload ใน `chrome://extensions`, **รีเฟรชแท็บ TikTok LIVE ด้วย `Ctrl+R`**, รีสตาร์ตโปรแกรม/รีเฟรชหน้า Web UI และสร้างรหัสจับคู่ใหม่

## กำหนดคำอ่านอีโมจิ (เหมือน YouTube)

ทั้ง **TikTok LIVE (TikFinity)** และ **TikTok LIVE (Extension)** มี Checkbox **อ่านอีโมจิด้วยคำที่กำหนดเอง** และช่อง **พจนานุกรมคำอ่านอีโมจิ** อยู่ภายในหัวข้อ **กำหนดการอ่านข้อความและข้อมูลพิเศษ** เหมือน YouTube LIVE ตั้งค่าแยกโหมดได้ เช่น

```text
😂 = หัวเราะ
❤️ = หัวใจ
GGWP = เก่งมาก
```

ค่าเริ่มต้นปิดไว้ เปลี่ยนคำอ่านเฉพาะข้อความที่จะส่งไปสร้างเสียง ไม่แก้คอมเมนต์ต้นฉบับที่รับมา และ **ไม่เปิดการอ่าน Gift** กลับมา รุ่น Extension v0.2.5 อ่านข้อความ `alt` ของรูปอีโมจิภายในคอมเมนต์เมื่อ TikTok แสดงรูปดังกล่าว โดยไม่ดึงป้ายระดับหรือยศเข้าเนื้อหาเสียง ดู [คู่มือการอ่านอีโมจิ](EMOJI_PRONUNCIATION_TH.md)

อัปเดต Source Project: รีสตาร์ต `Start-Dev.cmd` และรีเฟรช Web UI ส่วน Extension ให้กด Reload ใน `chrome://extensions` (ต้องแสดง v0.2.5), รีเฟรชแท็บ LIVE และจับคู่ใหม่

## การตั้งค่าชื่อผู้ส่ง

โปรแกรมสามารถอ่านชื่อผู้ส่งเป็น `คุณ Sprite Pam พิมพ์ว่า สวัสดีครับ` หรือใช้คำอื่นแทน `คุณ` และ `พิมพ์ว่า` ได้ตามที่ตั้งค่า การตั้งค่าแยกแต่ละโหมด YouTube/TikTok/Discord และบันทึกใน `data/settings/mode-voices.json`

ใน YouTube LIVE (API) และ YouTube LIVE (Browser) จะมีตัวเลือกเฉพาะ `@` หน้า *ชื่อผู้ส่ง* โดยค่าเริ่มต้นไม่อ่าน `@` นี้ ไม่เปลี่ยนเครื่องหมาย `@` ในข้อความคอมเมนต์เอง หากเคยตั้งกฎแทน `@ → คุณ` ในระบบแทนข้อความส่วนกลาง ให้ปิดกฎเดิมเพื่อไม่ให้กระทบคอมเมนต์

## สถานะการเชื่อมต่อและข้อจำกัด

หน้าต่างโปรแกรมและ Popup ของ Extension แสดงสถานะจับคู่/พบ DOM/จำนวนข้อความใหม่ และการมองเห็นแท็บ หาก Chrome ลดความถี่การทำงานเมื่อแท็บอยู่เบื้องหลัง ระบบอาจตามทันเมื่อ DOM มีการเปลี่ยนแปลง แต่ **ไม่สามารถรับข้อความที่ TikTok ไม่ได้ส่งหรือไม่แสดงใน DOM** ได้

เมื่อ Chrome แจ้ง `Extension context invalidated` ให้ Reload Extension, รีเฟรชหน้า LIVE และจับคู่ใหม่ เพราะสคริปต์จาก Context เดิมอาจยังค้างในแท็บ

ส่วนเสริมนี้ไม่ใช่เครื่องมือที่ TikTok รับรอง และ TikTok อาจจำกัดการดึงข้อมูลอัตโนมัติ ตรวจสอบสิทธิ์ตามข้อกำหนดของแพลตฟอร์มก่อนใช้งาน

**การอ่าน Gift ถูกถอดออกแล้ว:** รายการ Gift Event จาก Extension เก่าจะถูก Backend ข้าม ไม่ส่งเข้าคิวเสียง และ TikFinity ใช้เฉพาะ Chat Event
