# VoxWeaveTTS v0.12.17 — Voice Routing & Output Format

## อัปเดตหลัก

**แก้การเลือกโมเดล Wayu Paxa Edge และค่าปรับเสียงตามภาษา**

- เพิ่มปุ่ม **แก้ไขโมเดล / เสียง** ในแถวภาษาที่กำหนดไว้แล้ว เช่น **ภาษาไทย (th)** และภาษาอังกฤษ (en) โดยไม่ต้องลบภาษาแล้วเพิ่มใหม่
- ปรับหน้าแสดงรายการ Engine/Voice หลังเปลี่ยนค่าให้ตรงกับค่าที่เลือก และคง Speed / Gain / Pitch / Bass / Treble / Seed ของภาษานั้นเมื่อเปลี่ยนโมเดลหรือเสียง
- หลังติดตั้งแพ็กเกจ Universal .vwmodel v4 ผ่านหน้าเว็บ รายการ Engine/Voice ของตัวกำหนดภาษาจะรีโหลดโดยไม่ต้องปิดหน้าเว็บ
- แสดงคำอธิบายเมื่อเปิด **ใช้การเลือกโมเดลตามภาษา** หรือ **แยกอ่านข้อความตามภาษา** เพราะค่าปรับเสียงตามภาษาจะมีสิทธิ์ทับ Default Engine/Model และค่าปรับของโหมด
- ตรวจสอบแพ็กเกจ [NC / NonCommercial] Wayu Paxa Edge v1.0.0 ที่ผู้ใช้ติดตั้งจริง: Runtime พร้อมใช้งานและ Engine Registry พบ 12 เสียงสำหรับ th/en; ทดลองสร้างเสียงสองค่าความเร็ว พบว่าค่า Speed ส่งผลต่อผลลัพธ์จริง

**แก้ความหมายของ Audio Output: Auto เทียบกับ Manual**

- **Auto**: ทดลองรูปแบบเสียงที่อุปกรณ์รองรับพร้อม Resample / ปรับจำนวนช่องเสียงเมื่อจำเป็นโดยไม่เร่งหรือหน่วง Pitch/ความยาวเสียง
- **Manual (กำหนดเอง)**: บังคับ Sample Rate และ/หรือ Channels ตามตัวเลขที่เลือกไว้ ถ้า WAV ต้นทางต่างกันให้ Resample มายังค่านี้ ไม่เปลี่ยนค่าบังคับกลับเป็น Auto โดยเงียบ ๆ
- หากอุปกรณ์ไม่รองรับ Sample Rate/Channels ที่บังคับ ระบบจะแสดงข้อผิดพลาด หากใช้ตัวเล่นสำรอง WinMM ที่รับประกันค่าบังคับไม่ได้ ระบบจะไม่ลักลอบใช้ค่านั้น
- หน้าเว็บแสดงค่า **Output ที่เลือก / Sample Rate ของ WAV ต้นทาง / ค่าที่ใช้เล่นจริง** แยกกัน และไม่แสดงรูปแบบการเล่นเก่าราวกับเป็นค่าที่เพิ่งเปลี่ยน

## การใช้งานหลังอัปเดต

1. ปิด Server รุ่นเก่าตามปกติก่อนเปลี่ยนเวอร์ชัน และแตก ZIP Server Portable ในโฟลเดอร์ใหม่เพื่อหลีกเลี่ยงการเขียนทับไฟล์ที่กำลังใช้งาน
2. เก็บสำรองข้อมูลการตั้งค่าและแพ็กเกจโมเดลที่ติดตั้งในเวอร์ชันเก่าก่อนย้ายข้อมูลมายัง Portable ใหม่ ตามโครงสร้างข้อมูล/โมเดล v4 เดิม
3. เปิด Server แล้วใช้ Browser เข้าพอร์ตตามที่กำหนด เช่น `http://192.168.1.165:8775/`
4. เปิด **กำหนดโมเดลและเสียงตามภาษา** → กด **แก้ไขโมเดล / เสียง** ที่ภาษาไทย → เลือก Wayu Paxa Edge และเสียง → กด **กำหนดโมเดล** แล้ว **บันทึกการตั้งค่า**
5. ตรวจการเปิดใช้โมเดลตามภาษาหรือแยกภาษาในโหมด YouTube / STT ซึ่งอาจทำให้ค่าตามภาษามีผลเหนือค่า Default Engine/Model ของโหมด
6. ตั้งค่า Output เป็น **Auto** สำหรับการเลือกอัตราสุ่มที่เหมาะสมอัตโนมัติ หรือ **กำหนดเอง** เมื่อต้องการบังคับค่าที่อุปกรณ์รองรับ ตรวจสถานะรูปแบบเสียงจริงหลังเล่นครั้งถัดไป

ดูคู่มือ [Auto/Manual Output และ Voice Routing](AUDIO_ROUTE_OUTPUT_TH.md)

- `VoxWeaveTTS-Client-v0.12.17-portable.zip` — Remote Client เดิมสำหรับความเข้ากันได้ ไม่ได้พัฒนาเพิ่ม

แพ็กเกจหลัก **ไม่รวมโมเดลเสียงหรือ .vwmodel ของบุคคลที่สาม** โดยเฉพาะแพ็กเกจ NC ของ Wayu ซึ่งยังมีสิทธิ์ของผู้เผยแพร่เดิมและต้องติดตั้งแยกเอง

## การตรวจสอบและข้อจำกัด

ทดสอบการปรับ Speed กับ Wayu Paxa Edge ที่ติดตั้งจริงสองครั้งโดยไม่เปิดเสียงออกลำโพง (1.00× ประมาณ 1.975 วินาที; 1.45× ประมาณ 1.650 วินาที) และทดสอบการเลือกเสียงภาษาไทย, ค่า DSP ตามภาษา, Auto 24,000→192,000 Hz, การบังคับ Manual และกรณีอุปกรณ์ไม่รองรับ

การปรับ Sample Rate ไม่ช่วยสร้างรายละเอียดเสียงที่โมเดลไม่ได้สร้างไว้ตั้งแต่ต้น และยังไม่ได้ตรวจยืนยันคุณภาพเสียงกับการฟังจริงบนทุกอุปกรณ์หรือทุกแพลตฟอร์ม Live
