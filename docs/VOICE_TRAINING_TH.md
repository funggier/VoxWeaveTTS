# VoxWeaveTTS — แนวทางสร้างเสียงส่วนตัวและเทรนโมเดลภาษาไทย

> **แผนงานในอนาคตเท่านั้น** — ยังไม่มี Endpoint สำหรับฝึกโมเดลหรือ Voice Cloning; ใช้นโยบาย [Commercial-First License Policy](COMMERCIAL_LICENSE_POLICY_TH.md) ก่อนเลือกโมเดล/ฝึก/แจกจ่าย

## เหตุผลที่แยกระบบฝึกเสียงจากระบบอ่านคำ

การทำเสียงให้คล้ายเสียงของผู้ใช้มีเป้าหมายหลักคือ **Speaker Identity / Timbre** ส่วนการอ่าน “อมตะ”, “เซียน”, “ฮ่า ฮ่า ฮ่า” ให้ถูกต้องเกี่ยวข้องกับ **Text Normalization, G2P/Phonemes, Thai Tones, Prosody** และคุณภาพข้อมูลฝึก การฝึกเพื่อเลียนแบบเสียงจึง **อาจช่วยความเป็นธรรมชาติบางส่วน แต่ไม่รับประกันแก้คำอ่านผิด** โดยเฉพาะคำที่ข้อมูลฝึกไม่ครอบคลุม

ควรแยกความสามารถ:
1. **Voice Profile:** สร้างโปรไฟล์จากคลิปที่เจ้าของเสียงยินยอม โดยใช้ Engine ที่รองรับ Reference Audio
2. **Pronunciation Dictionary:** ผู้ใช้แก้คำอ่านหรือ IPA พร้อมบริบท/กฎ ใช้ได้หลาย Engine โดยไม่ต้องเทรนซ้ำ
3. **Fine-tuning:** เมื่อ Engine, License และอุปกรณ์เหมาะสม จึงฝึกปรับโมเดลด้วยเสียงและข้อความที่จัดแนวถูกต้อง
4. **Voice Style / Audio DSP:** ปรับ Pitch, Volume, EQ และอารมณ์ตามความสามารถของโมเดล แยกจากข้อมูลฝึก

**Candidate เริ่มต้น:** VoxCPM2 (ผู้พัฒนาประกาศ Apache-2.0 สำหรับ code และ weights) เพราะรองรับทั้งภาษาไทยและ LoRA Fine-tuning แต่ยังต้องตรวจ Dependency/Voice Rights/Training Data ก่อนแจกจ่ายหรือใช้งานเชิงพาณิชย์จริง

## รูปแบบข้อมูลที่ควรเตรียม

- ผู้ใช้เป็นผู้บันทึก/มีสิทธิ์ใช้เสียงของตนเองหรือได้รับอนุญาตชัดเจน
- สภาพการอัดที่สม่ำเสมอ: ไมโครโฟน ระยะห่าง ห้อง และระดับความดังใกล้เคียงกัน
- แยกคลิปตามประโยคหรือช่วงสั้น ๆ พร้อม Transcription ตรงกับเสียงจริง
- มีชุดอ่านทดลองเฉพาะ: วรรณยุกต์ 5 เสียง พยัญชนะที่สับสน คำว่า “อมตะ”, “เซียน”, “ฮ่า”, ชื่อบุคคล และศัพท์นิยาย
- แยก Train/Validation/Evaluation เพื่อวัดว่าดีขึ้นจริง ไม่วัดจากชุดฝึกเพียงอย่างเดียว
- เริ่มประเมิน Zero-shot ด้วยคลิปสั้นที่มีคุณภาพก่อน จำนวน/ความยาวข้อมูลสำหรับ Fine-tune ขึ้นกับโมเดลที่เลือกและต้องวัดผลจริง

## ข้อจำกัดเครื่อง

เครื่องเป้าหมายปัจจุบันตรวจพบ Intel Graphics ไม่ใช่ NVIDIA CUDA จึงยังไม่ควรสัญญาว่า Fine-tune โมเดลขนาดใหญ่ได้ดีหรือเร็วบนเครื่องนี้ แผนจะเริ่มด้วย Inference/Reference Voice และแยกการฝึกออกเป็น Worker ที่เลือก CPU/GPU/เครื่องอื่นได้ตามความสามารถจริง โดย **ไม่ส่งข้อมูลเสียงไป Cloud โดยไม่แจ้ง/ได้รับอนุญาต**

## การประเมินความถูกต้อง

**Speaker Similarity:** เทียบเอกลักษณ์เสียงกับต้นฉบับโดยผู้ฟังและเครื่องมือเท่าที่ตรวจสอบได้

**Pronunciation Accuracy:** ตรวจคำไทย เปรียบเทียบคำที่ออกเสียงผิดก่อน/หลังปรับ Dictionary, Engine และ Fine-tuning แยกกัน

**Naturalness:** ตรวจ Rhythm/Pause/Emotion ให้เหมาะกับนิยายกับแชทสด ไม่เอา Seed ที่เปลี่ยนคลื่นเสียงเล็กน้อยมาเป็นหลักฐานว่าเสียงดีขึ้น
