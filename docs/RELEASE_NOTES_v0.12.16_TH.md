# VoxWeaveTTS v0.12.16 — Core Status & Browser Controls

## สิ่งที่แก้ไข

**โหมด Computer / Core-owned TTS**

- แก้ปัญหา Dashboard ไม่แสดงสถานะของแหล่งข้อความทั้งหมด เมื่อมีโหมด VoxWeaveSTT (API) โดย Core รองรับการอ่านคิวของทุก Live Source ครบทั้ง 7 โหมด
- แสดงสถานะ **รับข้อความ**, **กำลังแปล/เตรียม**, **เตรียมแล้ว**, **กำลังสร้างเสียง**, **กำลังเล่นเสียง**, **อ่านสำเร็จ**, **ผิดพลาด/หยุด/ล้างคิว** ตามข้อมูลที่ Core กำลังทำจริง
- แสดง **ข้อความต้นฉบับ** เมื่อขั้นตอนการแปลยังไม่เสร็จ และแสดง **ข้อความที่ส่งเข้าโมเดลเสียงจริง** เมื่อ Core เตรียมข้อความและกฎการอ่านเสร็จแล้ว ไม่ใช้ข้อความต้นฉบับแทนผลแปล
- จัดลำดับแสดงรายการที่ **กำลังเล่นเสียง** ก่อนงานเก่าในคิว และผูกโหมด STT ที่กำลังเล่นกับ Workspace ของ STT จริง เพื่อให้ปุ่มหยุดถูกโหมด
- เก็บสถานะ Job ผิดพลาด/ข้าม/หยุดในประวัติชั่วคราวของ Core หลัง Job หมดอายุ และแสดงข้อผิดพลาดของ Dashboard เมื่อข้อมูลละเอียดเรียกไม่สำเร็จ

**ปุ่มควบคุม Browser**

- ปุ่มเชื่อมต่อ/หยุด และตัวเลือกอ่านอัตโนมัติอ่านสถานะปัจจุบันจาก Core เมื่อเปิดหน้าเว็บหรือรีเฟรช ไม่ใช้ค่าที่แท็บ Browser เดิมเคยถือไว้
- ในโหมด Computer สามารถปรับ **อ่านอัตโนมัติ** และ **รีเซ็ตคิวข้อความที่ยังไม่ได้เริ่มประมวลผล** ผ่านคำสั่ง Core แบบ Same-Origin และ Explicit Intent ได้ แม้เปิดเว็บใหม่ไม่มี Owner Token จากแท็บเดิม
- การรีเซ็ตไม่ลบ Job ที่รับเข้า Coordinator แล้ว เช่น งานแปล, งานสร้างเสียง, เสียงพร้อมเล่น หรือเสียงที่กำลังเล่น และมีการป้องกัน Race Condition ตอนรับข้อความเข้าคิว
- สถานะและปุ่มจะถูกอัปเดตจาก Snapshot ของ Server โดยใช้การรีเฟรชสถานะเดิม **ไม่มีการสร้าง Polling Loop, Source Connection หรือ TTS Worker ซ้ำ** เพียงเพราะรีเฟรช Browser

## วิธีทดลองหลังอัปเดต

1. ปิด Server รุ่นเก่าตามปกติ จากนั้นแตกไฟล์ ZIP ในโฟลเดอร์ Portable แยกต่างหาก; คัดลอกการตั้งค่าและโมเดล v4 ที่ติดตั้งแล้วตามความเหมาะสม โดยไม่เขียนทับไฟล์ข้อมูลที่กำลังใช้งาน
2. เปิด `VoxWeaveTTS.exe` หรือ `Start-Console.cmd` ตามปกติ และเปิด URL Browser ที่ Server แสดง (ค่าเริ่มต้น `http://127.0.0.1:8775/`)
3. เลือก **ทำงานบนคอมพิวเตอร์** แล้วเชื่อมต่อ YouTube/Discord/STT ตามที่ใช้งานจริง
4. ระหว่างมีข้อความใหม่ ให้ตรวจคิวที่กำลังแปล, ข้อความหลังแปล/เตรียม, กำลังสร้างเสียง, เสียงกำลังเล่น และประวัติอ่านจบ
5. รีเฟรชหน้าเว็บแล้วตรวจว่าปุ่ม **เชื่อมต่อ / หยุดรับข้อความ / อ่านอัตโนมัติ / รีเซ็ตคิว** สะท้อนค่าที่ Server ใช้อยู่ โดยไม่สร้างการเชื่อมต่อเพิ่ม
6. ทดลองรีเซ็ตคิวขณะที่มีรายการรออยู่: คิวที่ยังไม่เริ่มถูกลบ แต่เสียงที่เริ่มประมวลผลแล้วไม่ถูกยกเลิกโดยปุ่มรีเซ็ต

## Windows Portable

- `VoxWeaveTTS-v0.12.16-portable.zip` — Server/Core และ Web UI แบบ Windows Portable
- `VoxWeaveTTS-Client-v0.12.16-portable.zip` — ตัว Remote Client เดิมสำหรับความเข้ากันได้ **ไม่ได้เพิ่มความสามารถใหม่** เนื่องจากเน้นการพัฒนาฝั่ง Browser
- `SHA256SUMS-v0.12.16.txt` — ค่า SHA-256 ของ ZIP ทั้งสอง

**ไม่รวมโมเดลเสียงหรือแพ็กเกจ `.vwmodel` ที่ยังตรวจสิทธิ์ไม่ครบใน Server และ Client ZIP** ผู้ใช้ติดตั้งโมเดล v4 ที่เหมาะสมแยกต่างหาก
