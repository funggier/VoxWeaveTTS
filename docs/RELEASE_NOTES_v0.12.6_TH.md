# VoxWeaveTTS v0.12.6 — ติดตั้ง .vwmodel หลายไฟล์

- ใน **ตั้งค่า → จัดการ Model Packages** และส่วน **AI / Translation Model Packages** เปิดหน้าต่าง Windows ที่เลือกไฟล์ `.vwmodel` v4 ได้หลายไฟล์ในครั้งเดียว กด **Ctrl** เพื่อเลือกทีละไฟล์ หรือ **Shift** เพื่อเลือกเป็นช่วง
- โปรแกรมติดตั้งแบบออฟไลน์ทีละไฟล์ แสดงความคืบหน้า และสรุปว่าไฟล์ใดสำเร็จหรือมีปัญหา รายการที่เหลือทำต่อได้เมื่อแพ็กเกจหนึ่งติดตั้งไม่สำเร็จ
- แตก `VoxWeaveTTS-v0.12.6-portable.zip` แล้วเปิด `VoxWeaveTTS.exe` ใช้ไฟล์ `.vwmodel` v4 ที่มีอยู่ได้ ตรวจ SHA-256 กับ `SHA256SUMS-v0.12.6.txt`
