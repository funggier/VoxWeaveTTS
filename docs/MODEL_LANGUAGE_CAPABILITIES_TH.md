# ภาษาอ่านที่รองรับของแต่ละ TTS Engine

ในหน้า **โมเดลเสียงตามภาษา** สามารถกำหนดภาษาแต่ละภาษาให้ใช้ Engine/Model และ Voice ที่รองรับภาษานั้นได้ โดยเก็บค่า **Speed, Voice Controls, Seed และ Preset แยกอิสระตามภาษา** แม้เลือก Engine และ Voice เดียวกัน

## Engine ที่ตรวจสอบใน Source ปัจจุบัน

| Engine/Model | ภาษาอ่านที่รองรับสำหรับการเลือกโมเดลตามภาษา | วิธีเลือก |
|---|---|---|
| **[NC / NonCommercial] Wayu Paxa Edge** | **ไทย (th), อังกฤษ (en)** | **Voice ทั้ง 12 เสียงใช้ได้ทั้งสองภาษา** |
| FastThaiG2P Kokoro Thai, FastThaiG2P ThaiSom | ไทย (th) | Voice `thai_som` |
| **MakHam Paradee Thai** | **ไทย (th), อังกฤษ (en)** | Voice `paradee_thai` ตัวเดียวกันใช้กับทั้งสองภาษา |
| Vachana Thai และ Vachana 4 Voices | ไทย (th) | เสียงไทยที่ติดตั้ง |
| Kokoro Multilingual INT8 | อังกฤษ (en), สเปน (es), ฝรั่งเศส (fr), ฮินดี (hi), อิตาลี (it), ญี่ปุ่น (ja), โปรตุเกส (pt) | **เลือก Voice ของภาษานั้นโดยเฉพาะ**; ตัวอย่าง `af_heart` อ่านอังกฤษ, `jf_nezumi` อ่านญี่ปุ่น |
| MeloTTS Chinese ONNX | จีน (zh) | `zh_melo` |
| Supertonic 3 Multilingual INT8 | 31 ภาษา (`ar bg hr cs da nl en et fi fr de el hi hu id it ja ko lv lt pl pt ro ru sk sl es sv tr uk vi`) | เลือก `<language>_s0` หรือ `<language>_s1` ของภาษาที่ต้องการ |
| Ollama Speech (ทดลอง) | ขึ้นกับโมเดล Speech ที่ผู้ใช้กำหนด | ไม่สมมติว่ารองรับหลายภาษาจากชื่อโมเดล; ตั้งค่า `supported_languages` เฉพาะภาษาที่ตรวจสอบจากโมเดลจริงแล้ว |

**สำคัญ:** การติดตั้ง Engine กับการติดตั้ง Model/Runtime เป็นคนละเรื่อง ระบบแสดง Engine/Voice ที่พร้อมใช้งานเท่านั้น ภาษาที่ประกาศรองรับไม่ได้รับประกันคุณภาพหรือความแม่นยำทางสำเนียงของข้อความทุกประเภท

## วิธีใช้ MakHam สำหรับไทยและอังกฤษ

โมเดล MakHam Paradee ใช้เสียง `paradee_thai` ได้ทั้ง **ไทย (th)** และ **อังกฤษ (en)** โดยเลือก MakHam เป็น Engine ของทั้งสองภาษาในแท็บ **โมเดลเสียงตามภาษา** เหมือนกับ Wayu ไม่จำเป็นต้องติดตั้งโมเดลเพิ่ม ข้อจำกัดด้านการออกเสียงหรือสำเนียงของข้อความอังกฤษขึ้นกับตัวโมเดล

## วิธีใช้ Wayu สำหรับไทยและอังกฤษ

1. เปิดแท็บ **โมเดลเสียงตามภาษา**
2. เพิ่ม **ไทย (th)** แล้วเลือก **[NC / NonCommercial] Wayu Paxa Edge** และเสียงที่ต้องการ (เช่น `f_young_warm`)
3. เพิ่ม **อังกฤษ (en)** แล้วเลือก Wayu และ **เสียงเดียวกัน** ได้อีกครั้ง หรือจะเลือกเสียงอีกอันก็ได้
4. กดบันทึก และเปิด **ใช้การเลือกโมเดลตามภาษา** ในโหมดอ่านที่ต้องการ
5. หากต้องการอ่านข้อความที่สลับภาษาในไฟล์เสียงเดียว ให้เปิด **แยกข้อความตามภาษา** ในโหมดนั้นด้วย ระบบจะใช้ Route ตามส่วนภาษาที่ตรวจพบ

การตั้งค่าสองภาษาเก็บ **Voice Controls / Preset แยกกัน** การแก้ภาษาอังกฤษจะไม่เขียนทับค่าภาษาไทย

โมเดล Wayu มีน้ำหนักภายใต้ **CC BY-NC 4.0** และชื่อ Engine คงเครื่องหมาย **[NC / NonCommercial]** ชัดเจน **ไม่ได้รับรองสิทธิ์ใช้งานเชิงพาณิชย์** ไม่รวม Weights ใน Git หรือ Portable ZIP

## สำหรับผู้พัฒนา Engine/External Provider

ตัวบรรยาย Engine ใช้โครงสร้างนี้:

- `language`: ภาษาหลักเดิม เช่น `"th"` (ยังคงย้อนหลังได้)
- `supported_languages`: รายการภาษาที่ **Voice ทุกเสียง** อ่านได้ เช่น `["th", "en"]` สำหรับโมเดลเดียวที่อ่านได้หลายภาษา
- `voice_language_map`: สำหรับโมเดลที่แยกภาษาเป็นราย Voice เช่น `{"ko_s0": "ko", "en_s0": "en"}`
- หากไม่กำหนดสองฟิลด์ใหม่ ระบบยังคงทำงานแบบเดิมกับ Engine ภาษาเดียวและ Kokoro voice-prefix mapping

Provider ภายนอกที่ได้รับความเชื่อถือผ่านการอนุมัติโค้ด สามารถเพิ่มฟิลด์เสริมลงใน `provider.json` ได้ **โดยไม่ต้องแก้ Core**:

```json
{
  "language": "th",
  "supported_languages": ["th", "en"]
}
```

ตัวอย่างเป็นเพียงส่วนหนึ่งของ Manifest (ต้องมีข้อมูลอื่นตามรูปแบบ Provider เดิมด้วย) หากแต่ละ Voice อ่านคนละภาษา ให้ใช้ `voice_language_map` แทน **ไม่ใช้สองฟิลด์พร้อมกันใน Provider Manifest** ข้อมูลที่เพิ่มหรือเปลี่ยนต้องผ่านการยืนยัน SHA-256 และอนุมัติ Provider ใหม่ เนื่องจากไฟล์ Manifest เป็นส่วนหนึ่งของข้อมูลที่ได้รับอนุมัติ

สำหรับ Ollama Speech (ไม่ได้โหลดผ่าน Worker ของ VoxWeaveTTS) สามารถใส่ `"supported_languages": ["th", "en"]` ใน `data/settings/ollama-speech.json` เมื่อมั่นใจว่าโมเดล Speech รองรับจริง ไม่เกี่ยวกับการตั้งค่า Ollama สำหรับการแปล และการตรวจสถานะ Speech ของ Ollama ยังคงเป็นขั้นตอนแยกต่างหาก
