# VoxWeaveSTT (API) — การรับข้อความถอดเสียง

## ภาพรวม

VoxWeaveTTS มีโหมด **VoxWeaveSTT (API)** เป็นแหล่งข้อความอิสระ ใช้ Core ของ TTS (กฎข้อความ การแปลภาษา การกำหนดเสียงตามภาษา คิว และ Subtitle) เช่นเดียวกับแหล่ง Live อื่น ไม่ import โค้ดหรือไฟล์โมเดลจาก VoxWeaveSTT

## เครื่องเดียวกัน

1. เปิด VoxWeaveSTT Server และเริ่มถอดเสียงตามปกติ (ค่าเริ่มต้น `127.0.0.1:8766`)
2. เปิด VoxWeaveTTS → **VoxWeaveSTT (API)** → ตั้ง IP `127.0.0.1`, Port `8766`
3. กด **เชื่อมต่อ STT**; TTS Core จะอ่าน `GET /api/status` และ `GET /api/sessions/{id}/events?after=SEQ`
4. เมื่อ STT สร้าง `transcript.final` จะแปลงเป็นข้อความแหล่งข้อมูลและส่งต่อเข้าสู่คิว TTS
5. กด **หยุดรับข้อความ** เพื่อหยุดเฉพาะการเชื่อมต่อ; STT ไม่ถูกปิดโดย TTS

ถ้า STT ยังไม่เริ่ม Session, TTS จะรอ Session ใหม่โดยไม่อ่านข้อความเก่า ณ เวลาที่กดเชื่อมต่อ หาก STT หยุด Session จะพยายามเก็บ Final ที่ flush เมื่อหยุดด้วย

## LAN (ต้องเปิดใช้เอง)

VoxWeaveSTT มี HTTPS LAN Gateway แยกจาก HTTP loopback ปกติ ให้เปิดบริการที่ STT ก่อน แล้วกรอก IP/Port ของ Gateway (ปกติ Port 8768) ใน TTS กา **ใช้ HTTPS LAN**, กรอก **PIN 8 หลัก** และ **SHA-256 Certificate Fingerprint** ของ STT

TTS ปักหมุด Certificate Fingerprint ก่อนส่ง PIN หรือ Cookie, ใช้ Cookie จับคู่ในหน่วยความจำ และปฏิเสธ HTTP ที่ไม่ใช่ 127.0.0.1 ไม่เปิดให้ใช้ IP ภายนอกสาธารณะและไม่ยอมรับ TLS ที่ Fingerprint ไม่ตรง

เมื่อ PIN ถูกใช้แล้วหรือ STT เริ่ม Server ใหม่ ต้องจับคู่ใหม่ตามกลไกของ STT

## การประมวลผล/คิว

- รับ `transcript.final` เท่านั้น (ไม่อ่าน Partial ซ้ำ)
- เคารพลำดับ Event ด้วย `api_sequence` และ dedupe ด้วย Session + Segment + Revision
- ไม่ตีความข้อความจาก STT เป็นคำสั่งหรือสิทธิ์ระดับผู้ดูแล
- การอ่านอัตโนมัติ/สุ่มลดคิว/เตรียมเสียงล่วงหน้า/กรองข้อความและเสียงใช้การตั้งค่าของโหมดนี้แยก
- เลือก **ทำงานบนคอมพิวเตอร์** ในตั้งค่า TTS เพื่อให้ Core สร้างและเล่นเสียงได้โดยไม่พึ่งการเปิดหน้าเว็บ
- เมื่อทำงานผ่าน Browser จะใช้ระบบเล่นเสียงเดิมของ Browser รวมถึงข้อจำกัด Autoplay
- สลับไปแท็บอื่นหรือรีเฟรชหน้าเว็บไม่ต้องตัดการรับ STT ที่ Core เมื่อเชื่อมต่ออยู่
- หาก STT รับ Desktop Loopback ของอุปกรณ์ที่ TTS เล่นเสียง ควรเลือกอุปกรณ์รับเสียงอื่น/แยก routing ป้องกันวงจรเสียงสะท้อนกลับ

## ข้อจำกัดปัจจุบัน

ยังไม่ใช่ระบบ Sync พากย์ตามเวลาเสียงต้นฉบับ หรือ Speaker Diarization แต่เป็นแหล่งข้อความแบบทีละ Final ที่เข้าระบบ TTS เดิม
