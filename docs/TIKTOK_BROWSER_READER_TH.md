# TikTok LIVE (Browser) — เลิกใช้แล้ว

โหมด Browser รุ่นทดลองเดิมเปิด Chrome ผ่าน CDP ด้วยโปรไฟล์แยก แต่ไม่สามารถรับคอมเมนต์จาก LIVE ของผู้ใช้ได้ แม้ Chrome ปกติและ Chrome Incognito อ่านคอมเมนต์ได้ ขณะเดียวกันการเข้าสู่ระบบในหน้าต่างที่โปรแกรมเปิดยังถูกจำกัดจำนวนครั้ง

จึง **ยุติการใช้งานโหมด Browser นี้** และเปลี่ยนเป็น **TikTok LIVE (Extension)** ซึ่งผู้ใช้เปิดแท็บ TikTok LIVE ใน Chrome เอง และติดตั้งส่วนเสริมแบบ Unpacked ด้วยสิทธิ์ที่ระบุชัดเจน ระบบจับคู่กับโปรแกรมผ่านรหัสครั้งเดียวและส่งข้อความผ่าน Loopback เท่านั้น

ดูคู่มือปัจจุบัน: [TikTok LIVE (Extension) — คู่มือฉบับใหม่](TIKTOK_EXTENSION_READER_TH.md)

ส่วน **TikTok LIVE (TikFinity)** ยังคงทำงานแยกโดยไม่เปลี่ยนแปลง

ทั้งนี้ส่วนเสริมยังเป็นฟีเจอร์ทดลอง ไม่มีการรับประกันว่าจะใช้งานกับ TikTok LIVE จริงได้ และผู้ใช้ต้องตรวจสอบสิทธิ์ในการดึงข้อมูลตามข้อกำหนดของ TikTok ก่อนใช้งาน
