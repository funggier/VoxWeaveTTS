# VoxWeaveTTS v0.12.8 — ส่งข้อความ Live เป็นชุดให้ Ollama

เปิด **ส่งหลายข้อความในพรอมป์เดียวให้ Ollama** ที่ **ตั้งค่า → AI Processing & Translation** และเปิด **เตรียมและสร้างเสียงข้อความถัดไปล่วงหน้า** ในโหมด Live ที่ใช้งาน

- **จำนวนข้อความสูงสุดต่อชุด** ใช้ได้ตั้งแต่ 1–64 และ **จำนวนข้อความขั้นต่ำก่อนส่งชุด** ใช้ได้ตั้งแต่ 1 ถึงค่าสูงสุดที่ตั้งไว้ ค่าเดิมที่บันทึกไว้ใน v0.12.7 จะถูกอ่านเป็นค่าชุดในรุ่นนี้
- เมื่อกดบันทึก คิวที่ยังไม่ได้ส่งจะใช้ค่าขนาดและขั้นต่ำล่าสุด ชุดที่กำลังแปลจะส่งผลกลับตามเดิม ข้อความใหม่ที่เข้าคิวหลังปิดสวิตช์จะใช้การแปลแบบข้อความเดี่ยว
- โปรแกรมส่ง JSON หนึ่งคำขอต่อชุด และจับคู่คำแปลด้วยรหัสข้อความ คิวสร้างเสียงและคิวอ่านใช้ลำดับเดิม รวมถึงข้อความที่ไม่ต้องแปล หากผลของบางรายการใช้ไม่ได้ โปรแกรมจะใช้ตัวเลือกสำรองเฉพาะรายการนั้น
- คิวแบบชุดส่งทีละชุด ข้อความท้ายคิวจะส่งเองหลังรอสะสมประมาณ 150 มิลลิวินาทีเมื่อมีช่อง ชุดที่ยาวอาจถูกแบ่งตามขนาดข้อความรวม

## พรอมป์และเครื่องมืออ้างอิง

- โหมด **ทำตามพรอมป์** ใช้ Priority Instructions ก่อน Custom Prompt เลือกภาษาผลลัพธ์เพื่อกำหนดภาษา หรือใช้ **ไม่ระบุภาษา** เพื่อให้พรอมป์กำหนดงานและภาษา ค่ารูปแบบงานสำเร็จรูปจากรุ่นก่อนจะถูกข้าม ถ้าทั้งสองช่องพรอมป์ว่าง โปรแกรมจะส่งข้อความผ่านโดยไม่เรียก Ollama
- **อนุญาต AI Tool Calling** ใช้กับ Ollama ทั้งโหมดแปลภาษาและโหมดทำตามพรอมป์ ในโหมดแปล เครื่องมือช่วยค้นความหมายและบริบทจากแหล่งที่อนุญาต ส่วน Priority Instructions และ Custom Prompt กำหนดศัพท์และสำนวนได้ เมื่อทั้งสองช่องว่าง โปรแกรมใช้คำสั่งแปลตามปกติ
- การแปลแบบชุดใช้พรอมป์เริ่มต้นหนึ่งคำขอต่อชุด การเรียกเครื่องมือจะเพิ่มรอบส่งผลกลับให้ Ollama ตามจำนวนที่ตั้งไว้ โปรแกรมนำผลเดิมมาใช้เมื่อมีคำขอเครื่องมือที่เหมือนกันในชุดเดียวกัน

ทดสอบเพิ่มเติมด้วย `qwen3.5:4b` ใช้คำสะกดทั้งสองคำจากอภิธานศัพท์ในไฟล์ที่อนุญาตได้จริง โหมดทำตามพรอมป์ให้ผลภาษาไทยเมื่อกำหนดภาษาไทย และให้ผล `READY` ตามพรอมป์เมื่อเลือกไม่ระบุภาษา

## ผลทดสอบตัวอย่างบน Windows

ใช้โมเดล Ollama ที่ติดตั้งอยู่แล้ว ทดสอบทีละตัวกับข้อความจำลองชุดเดียวกัน 5 ข้อความ มีภาษาอังกฤษ ญี่ปุ่น เกาหลี และไทยปนอังกฤษ ส่งในพรอมป์เดียวและแปลเป็นไทย เวลารวมการโหลดโมเดล รอบทดสอบเริ่มด้วย RAM ว่างประมาณ 17 GiB หลังคืน RAM จากโมเดล 27B

| โมเดล | ผ่านการตรวจของโปรแกรม | เวลา / 5 ข้อความ | ข้อสังเกตจากตัวอย่าง |
| --- | --- | --- | --- |
| `qwen3.5:0.8b` | 2/5 | 6.5 วินาที | 3 รายการใช้ข้อความเดิม |
| `qwen3:1.7b` | 5/5 | 6.9 วินาที | บางข้อความความหมายเพี้ยนและมีคำแปลซ้ำข้ามรายการ |
| `lfm3-vl:2b` | 5/5 | 6.6 วินาที | บางข้อความแปลคำและช่วงเวลาผิด |
| `qwen3.5:4b` | 5/5 | 15.8 วินาที | รักษาความหมายได้ดีที่สุดในชุดนี้ |
| `qwen3.5:9b` | 5/5 | 21.8 วินาที | แปลคำว่า stream เป็นสายน้ำในตัวอย่างหนึ่ง |

`qwen3.5:4b` ยังแปลผ่าน **10/10 ข้อความใน 22.8 วินาที** ในการลองเพิ่มฝรั่งเศส สเปน จีน และอังกฤษอีก 5 ข้อความ ผลนี้ใช้เลือกโมเดลเบื้องต้น การผ่านการตรวจหมายถึงโปรแกรมรับโครงสร้างและคำแปลได้ คุณภาพและเวลาจะเปลี่ยนตามข้อความ ขนาดชุด การตั้งค่า Ollama และทรัพยากรเครื่อง
