# การอ่านหลายภาษาภายในข้อความเดียว (เลือกเปิด–ปิดได้)

สถานะ: ฟีเจอร์ใน Source หลัง Release v0.9.1; ยังไม่รวมอยู่ใน Release v0.9.1 ที่เผยแพร่ก่อนหน้านี้

## ตัวอย่าง

ข้อความต้นฉบับ:
`ผมอยากทำComputer ผม ให้มันลื่นกว่านี้ lol`

เมื่อเปิด **แยกอ่านข้อความตามภาษา (รวมเสียงเป็นไฟล์เดียว)** จะได้ลำดับ:

1. **th** — `ผมอยากทำ` → โมเดลเสียงภาษาไทย
2. **en** — `Computer ` → โมเดลเสียงภาษาอังกฤษ
3. **th** — `ผม ให้มันลื่นกว่านี้ ` → โมเดลเสียงภาษาไทย
4. **en** — `lol` → โมเดลเสียงภาษาอังกฤษ

ระบบประมวลผลทุกช่วงตามลำดับแล้วต่อ PCM16 แบบ mono เป็น **WAV ไฟล์เดียว** โดยปรับ Sample Rate ระหว่างโมเดลก่อนรวม เช่น Kokoro ไทย/อังกฤษ 24 kHz และ MeloTTS จีน/Supertonic เกาหลี 44.1 kHz ไม่ใช่การส่งหลายไฟล์ไปเล่นเรียงบนหน้าเว็บ และไม่เพิ่มจำนวนรายการในคิวแชท

## วิธีใช้งาน

1. เข้าโหมดที่ต้องการ เช่น **สร้างเสียง**, **อ่านเอกสาร**, **YouTube LIVE**, **Discord** หรือ **TikTok LIVE**
2. ขยายหัวข้อ **กำหนดการอ่านข้อความและข้อมูลพิเศษ**
3. เปิดสวิตช์ **แยกอ่านข้อความตามภาษา (รวมเสียงเป็นไฟล์เดียว)** ซึ่ง **ปิดเป็นค่าเริ่มต้น** และบันทึกแยกเป็นรายโหมด
4. กำหนดโมเดลในแท็บ **โมเดลเสียงตามภาษา** ให้ตรงกับภาษาที่ใช้จริง เช่น th → MakHam, en → Kokoro, zh → MeloTTS, ko → Supertonic, ja → Kokoro + Misaki
5. ทดสอบข้อความที่มีหลายภาษา; ปิดสวิตช์เมื่อไม่ต้องการแบ่งช่วง ระบบจะกลับไปใช้การเลือก Engine/Voice แบบเดิมทั้งประโยค

สวิตช์นี้ **เป็นอิสระจาก** ตัวเลือก **ใช้การเลือกโมเดลตามภาษา** ที่มีอยู่ก่อน หากเปิดเฉพาะการแยกช่วงก็จะใช้แผนผังโมเดลตามภาษาสำหรับแต่ละช่วงได้เลย ในกรณีไม่พบโมเดลที่กำหนดให้ภาษา จะย้อนกลับไปใช้ **Default Engine / Model** ของโหมดนั้น (อาจอ่านภาษาที่ไม่รองรับได้ไม่ถูกต้อง) หากโมเดลที่กำหนดไว้ถูกถอนการติดตั้งหรือ Runtime ไม่พร้อม การสร้างเสียงจะรายงานว่า Engine ไม่พร้อมแทนการเปลี่ยนแบบเงียบ ๆ

## การแปลข้อความ

ระบบจะดำเนินตามลำดับ:
`กฎเฉพาะโหมด → กฎกลางก่อน AI → แปล/ประมวลผล AI (ถ้าเปิด) → กฎกลางหลัง AI → แยกช่วงภาษาจากข้อความที่นำไปอ่านจริง → เลือก Engine/Voice ต่อช่วง → สร้าง/รวม WAV → Subtitle`

ระบบ **ไม่บังคับทุกช่วง** ให้อ่านตามภาษาเป้าหมายที่กำหนดในการแปล หากบางช่วงแปลไม่สำเร็จหรือโมเดลส่งภาษาอื่นกลับมา จะใช้ระบบแยกช่วงตามตัวอักษรจากผลลัพธ์ที่ได้จริง เช่น ข้อความไทยที่หลงเหลืออยู่ในคำแปลจีนจะยังถูกส่งไปโมเดลไทย (ถ้ากำหนดไว้)

## ข้อจำกัด

- เป็นการแยกแบบ **Unicode Script Heuristic** ไม่ใช่ AI Language Identification: ตัวอักษรละตินถูกมองเป็น `en` โดยค่าเริ่มต้น; ภาษาฝรั่งเศส เยอรมัน สเปน อินโดนีเซีย ฯลฯ ที่ใช้ตัวอักษรคล้ายกันยังไม่สามารถจำแนกภาษาได้แน่นอน
- อักษรจีน (Han) ที่เขียนติดกับฮิรางานะ/คาตากานะจะมองเป็นญี่ปุ่น; คันจิที่ไม่มีคานะเลยอาจสับสนกับจีน ต้องระบุภาษา/แยกต้นฉบับอย่างเหมาะสม
- ช่องว่าง เครื่องหมายวรรคตอน อีโมจิ และตัวเลขที่ไม่มีตัวอักษรจะติดอยู่กับช่วงก่อนหน้า; ไม่มีการสูญเสียตัวอักษรจากการแบ่งช่วง
- Subtitle ยังใช้ข้อความที่ผ่านกฎกรองเดิมและรวมเป็นช่วงแสดงผลตาม Segment ต้นฉบับ ไม่รับประกันการจัดเวลาให้ตรงแต่ละคำ (Word Alignment) การแยกเสียงไม่ได้เปิดเผยข้อความที่ตั้งค่า Skip/Mask ไว้
- การเปลี่ยนเสียงหลายครั้งเพิ่มเวลา CPU และใช้โมเดล/หน่วยความจำมากขึ้น โดยจำกัดสูงสุด 96 ช่วงต่อรายการเพื่อป้องกันคิวทำงานหนักเกิน
- ระบบไม่ได้ตั้งค่าหรือดาวน์โหลดโมเดลตามภาษาให้โดยอัตโนมัติ และจะไม่เปลี่ยนผลคำแปลหรือเติมคำใหม่
