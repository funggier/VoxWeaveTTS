# VoxWeaveTTS — ช่องทางเชื่อมต่อผ่าน LAN (Server / Browser / Remote Client)

## เลือกช่องทางให้ตรงกับสิ่งที่ต้องการ

| ต้องการ | เปิดด้วย | ตั้งค่าที่ไหน | พอร์ตตัวอย่าง | ต้องใช้ Remote Client หรือไม่ |
|---|---|---|---|---|
| **ควบคุม VoxWeaveTTS ผ่าน Browser** | Firefox/Browser จากคอมอีกเครื่องหรือโทรศัพท์ | **VoxWeaveTTS.exe → Network** บนเครื่อง Server | **8775** (เปลี่ยนได้) | **ไม่ต้อง** |
| **ฟังเสียงสดบน Browser** | หน้า **Live Audio Listener** พร้อมโทเคนรับฟัง | แท็บ **ตั้งค่า** → Live Audio Listener | **8766** (เปลี่ยนได้) | **ไม่ต้อง** |
| **ควบคุมด้วยโปรแกรม Remote Desktop Client** | VoxWeaveTTS-Client.exe | แท็บ **ตั้งค่า** → **Remote Desktop Client API** (ตัวเลือกขั้นสูง) | **8776** (เปลี่ยนได้) | **ต้องใช้** |

พอร์ตทั้ง 3 ประเภทมีหน้าที่ต่างกัน และ **ห้ามตั้งหมายเลขซ้ำกับพอร์ตของเว็บควบคุมที่ใช้งานอยู่** ค่า 8775, 8766 และ 8776 เป็นเพียงตัวอย่าง ไม่ใช่พอร์ตบังคับ

## 1. เปิด Web Control จากคอมพิวเตอร์/โทรศัพท์ใน LAN

1. บนเครื่อง Server เปิด `VoxWeaveTTS.exe` เลือก **Network → LAN** แล้วเลือก IPv4 ของเครื่อง Server (เช่น `192.168.1.165`) หรือเลือก **All IPv4 (0.0.0.0)** หากต้องการเปิดรับทุกการ์ดเครือข่าย
2. ตั้ง **Port** เช่น `8775`, **Username** (ค่าเริ่มต้น `voxweave` เปลี่ยนได้) และ **Password** อย่างน้อย 4 ตัวอักษร แล้วคลิก **Apply & Restart**
3. จากคอมพิวเตอร์/โทรศัพท์ที่อยู่ LAN เดียวกัน เข้า `http://192.168.1.165:8775/` (เปลี่ยน IP/Port ให้ตรงกับ Server) แล้วเข้าสู่ระบบด้วยบัญชีชุดที่ตั้งใน **Launcher**
4. ใน Web UI เลือก **ตั้งค่า → ควบคุม Server ผ่าน Browser ใน LAN** เพื่อตรวจ IP/Port, ชื่อผู้ใช้ และคัดลอกลิงก์

**สำคัญ:** `127.0.0.1` ใช้ได้เฉพาะเครื่องที่เปิด Server; บนโทรศัพท์จะหมายถึงโทรศัพท์เครื่องนั้น ไม่ใช่ Server ส่วน `0.0.0.0` เป็นค่าเปิดรับของ Server **ห้ามกรอกเป็น URL ของ Client** ใช้ IP จริง เช่น `192.168.1.165` แทน

ค่าหน้าเว็บหลักเก็บที่ **`data/network.json`** (พาธสัมพันธ์กับโฟลเดอร์ Portable) และต้องเริ่ม Core ใหม่หลังเปลี่ยนค่า Web UI แสดงค่าที่กำลังใช้งานจริง ส่วน URL สำหรับ Server ที่เลือก All IPv4 เป็นเพียงตัวอย่างจากการตรวจเครือข่าย หากมีหลาย NIC ควรตรวจด้วย `ipconfig`

**ถ้าเครื่องอื่นเปิดเว็บไม่ได้:** ตรวจว่า Server ใช้ LAN/All IPv4 ไม่ใช่ Local, คัดลอก IP จริง, ตรวจพอร์ตที่เปิดอยู่, อนุญาต Windows Firewall สำหรับพอร์ตที่ตั้ง และตรวจว่าอุปกรณ์อยู่ในเครือข่ายที่ติดต่อกันได้

## 2. รับฟังเสียงสดด้วย Browser

บน Web Control เลือก **ตั้งค่า → ส่งเสียงออกทาง → Live Broadcast** แล้วเปิดลิงก์ **Live Audio Listener** บนอุปกรณ์ผู้ฟัง และกดเปิดรับเสียงหนึ่งครั้ง ลิงก์มีโทเคนเฉพาะสำหรับการฟัง ไม่ใช่ Username/Password ของเว็บควบคุม

IP/Port ของ Live Audio Listener ตั้งแยกได้ที่ **ตั้งค่า → Browser รับฟังเสียงสด → กำหนด IP/Port (ขั้นสูง)** และเริ่ม Core ใหม่เมื่อเปลี่ยนค่า

การฟังสดไม่ทำให้ผู้ฟังเข้าถึงการตั้งค่า Model Packages หรือ API ของเว็บควบคุม ข้อมูลเสียงส่งเป็น PCM ต่อเนื่อง ไม่ใช่การดาวน์โหลด WAV ทั้งไฟล์

## 3. Remote Desktop Client API — ยังไม่เน้นพัฒนา

เมนูนี้พับเก็บไว้ใต้หัวข้อ **Remote Desktop Client API (ขั้นสูง)** ใช้เฉพาะโปรแกรม Client Portable แยก ไม่ใช่ Firefox/Browser และ **ไม่จำเป็น** หากต้องการใช้ Browser จากเครื่องอื่น

การตั้งค่าจัดเก็บที่ **`data/settings/network.json`** ซึ่งเป็นคนละไฟล์กับ Web Control โดย Remote Client API มี Username/Password แยกต่างหาก (รหัสผ่านฝั่ง Remote Client API เก็บเป็นแฮช) สามารถเลือกปิดไว้ได้ โดยไม่กระทบ Web Control

## ตัวอย่างและข้อควรระวัง

- ใช้คอมเครื่องเดียว: Web Control `127.0.0.1:8775`, ไม่จำเป็นต้องเปิด Remote Client API
- ใช้คอม Server + โทรศัพท์ควบคุม: เปิด Server LAN `192.168.1.165:8775`, โทรศัพท์เปิด URL นี้และเข้าสู่ระบบด้วยบัญชีจาก Launcher
- ใช้คอม Server + โทรศัพท์ฟังเสียงอย่างเดียว: เปิดลิงก์ Live Listener ของพอร์ต `8766` โดยใช้โทเคนจากหน้า Settings
- ใช้โปรแกรม Client แยกจริง ๆ: เปิด Remote Desktop Client API แยก เช่น `192.168.1.165:8776`

**ความปลอดภัย:** Web Control และ Remote API ใช้ HTTP ภายใน LAN; อย่า Forward พอร์ตออกอินเทอร์เน็ตโดยตรง หากต้องเข้าจากภายนอกให้ใช้ VPN ที่เชื่อถือได้ พร้อมรหัสผ่านแข็งแรง รหัสสั้น 4 ตัวอักษรเป็นเพียงขั้นต่ำสำหรับการตั้งค่า
