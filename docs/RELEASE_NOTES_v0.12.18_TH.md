# VoxWeaveTTS v0.12.18 — รีเซ็ตคิว Core และโหมดไม่สร้างเสียง

## รายการปรับปรุง

### รีเซ็ตคิวข้อความทำงานกับคิว Core จริง

- แก้ปุ่ม **รีเซ็ตคิวข้อความ** ในโหมดทำงานบนคอมพิวเตอร์ (Core) ให้กดได้แม้จำนวนข้อความต้นทางเป็นศูนย์ หากยังมีงานแปล/เตรียม/สร้างเสียงหรือเสียงรอเล่นในคิว
- ล้างทั้งข้อความ Pending ของ Source, Buffer ที่ยังไม่ได้ส่งต่อ, งานใน Coordinator ที่รอแปล/สร้าง WAV/รอเล่น และ Replay ที่ยังไม่เริ่ม สำหรับแหล่งข้อความที่เลือก
- รักษาเสียงที่กำลังเล่นและงานปัจจุบันไว้ โดยไม่ตัดการเชื่อมต่อกับ YouTube/TikTok/Discord/STT และไม่ล้างคิวของแหล่งอื่น
- ป้องกันการแข่งขันระหว่าง Reset กับการนำข้อความเข้า HTTP/TTS ที่อาจทำให้ข้อความเก่ากลับเข้ามาใหม่
- แสดงจำนวนงานที่ล้าง รวมถึงงาน Coordinator ที่ถูกยกเลิก

### เพิ่มตัวเลือก **ไม่สร้างเสียง** ในแท็บตั้งค่า

- **ตั้งค่า → การประมวลผลข้อความ (ไม่สร้างเสียง)** สามารถเลือกเป็นรายโหมดได้ 7 โหมด: YouTube LIVE (API / Browser), TikTok LIVE (TikFinity / Extension), Discord, Discord Client และ VoxWeaveSTT (API)
- เมื่อเปิดตัวเลือกนี้ Core ยังคงรับแชท จัดการกฎกรอง/แทนคำและประมวลผล AI/Translation ตามการตั้งค่าที่บันทึกไว้ แต่ **ไม่เลือก Engine เสียง ไม่สร้าง WAV ไม่สั่ง Worker Render และไม่เปิดเสียง**
- ถ้าเปิดระบบแปลภาษา ผลที่แสดงคือข้อความหลังแปลและกฎหลัง AI; ถ้าไม่เปิด AI หรือเลือกไม่แปล จะแสดงข้อความที่ผ่านกฎแทนคำ/กรองตามปกติ
- มีสถานะ **แสดงข้อความแล้ว (ไม่สร้างเสียง)** และประวัติข้อความใน Core Dashboard ที่เห็นได้หลัง Browser Refresh; ไม่บันทึกเป็นเสียงที่อ่านสำเร็จหรืออ้างว่ามีไฟล์เสียง
- รองรับทั้งคิว Browser แบบตามลำดับปกติและคิวเตรียมล่วงหน้า โดยไม่เปิดการเล่นเสียง และใช้ API ตั้งค่ากลางแบบ Revision เพื่อป้องกันบันทึกทับจากอีกแท็บ
- **ค่าเริ่มต้น: ปิดทุกโหมด** เพื่อรักษาพฤติกรรมสร้างเสียงเดิม

## ขั้นตอนใช้งาน

1. สำรอง `data/settings` และแพ็กเกจโมเดล v4 ของ Server เดิมก่อนย้ายเวอร์ชัน
2. ปิด Server เดิมตามปกติ แล้วแตก ZIP v0.12.18 ในโฟลเดอร์ใหม่ (ไม่แนะนำให้ทับไฟล์ที่กำลังใช้งาน)
3. เปิดโปรแกรมและเข้าผ่าน Browser ที่ IP/Port ของ Server เช่น `http://192.168.1.165:8775/`
4. หากต้องการเฉพาะข้อความ: เปิด **ตั้งค่า** → ติ๊ก **ไม่สร้างเสียง** สำหรับโหมดที่ต้องการ → บันทึก AI Settings จากหน้าเดิม
5. หากต้องการแปล: เปิด AI Processing และเลือก Translate/ภาษาปลายทาง; หากต้องการข้อความเดิม ให้ปิด AI หรือเลือกไม่แปล
6. ปุ่ม **รีเซ็ตคิวข้อความ** จะล้างงานที่รออยู่ใน Core ของแหล่งนั้น ไม่หยุดเสียงปัจจุบันและไม่ตัดการเชื่อมต่อ

อ่านรายละเอียด [คู่มือโหมดไม่สร้างเสียงและรีเซ็ตคิว](NO_SPEECH_MODE_TH.md) และ [คู่มือ Core Live Status](CORE_STATUS_CONTROLS_TH.md)
