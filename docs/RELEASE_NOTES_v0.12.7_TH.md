# VoxWeaveTTS v0.12.7 — แปลข้อความ Live พร้อมกันด้วย Ollama

- เปิดสวิตช์ **แปลข้อความ Live พร้อมกันด้วย Ollama** ที่ **ตั้งค่า → AI Processing & Translation** แล้วใช้กับโหมด Live ที่เปิด **เตรียมและสร้างเสียงข้อความถัดไปล่วงหน้า**
- ตั้ง **จำนวนข้อความที่แปลพร้อมกันสูงสุด** ได้ 1–64 และตั้ง **ขั้นต่ำของข้อความสะสมก่อนส่ง** ได้ตั้งแต่ 1 ถึงค่าเพดาน ใช้เพดานร่วมกันทุกโหมด Live ตัวเลือกปิดเป็นค่าเริ่มต้น และเมื่อเปิด ค่าตั้งต้นคือเพดาน 2 ขั้นต่ำ 1
- เมื่อไม่มีงานกำลังแปล โปรแกรมส่งข้อความได้ทันที ระหว่างแปล หากมีช่องว่างและข้อความรอถึงขั้นต่ำ โปรแกรมเติมช่องทันที หากสะสมไม่ถึงขั้นต่ำ ระบบเปิดช่วงรอสั้นประมาณ 150 มิลลิวินาทีเพื่อให้รายการท้ายคิวเดินต่อได้
- ผลแปลกลับมาสลับลำดับได้ โปรแกรมส่งเข้า TTS และอ่านตามลำดับเดิมของแต่ละโหมด รวมถึงข้อความที่ผ่านกฎแล้วไม่ต้องส่งแปล
- จำนวนที่ Ollama ประมวลผลจริงขึ้นกับการตั้งค่าเซิร์ฟเวอร์ โมเดล และหน่วยความจำ ผลทดสอบคิวใช้ Ollama จำลองที่ตั้งเพดาน 20 และขั้นต่ำ 10

แตก `VoxWeaveTTS-v0.12.7-portable.zip` แล้วเปิด `VoxWeaveTTS.exe` ใช้แพ็กเกจ `.vwmodel` v4 เดิมได้ ตรวจไฟล์ ZIP กับ `SHA256SUMS-v0.12.7.txt`
