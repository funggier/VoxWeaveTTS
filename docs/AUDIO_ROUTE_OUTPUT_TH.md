# VoxWeaveTTS — ค่าเสียงตามภาษาและ Sample Rate ของ Output

## ความหมายของ Auto และกำหนดเอง

**WAV ต้นทาง (Model Sample Rate)** ถูกกำหนดโดยแต่ละแพ็กเกจเสียง ไม่ใช่ค่าที่ผู้ใช้เลือกในอุปกรณ์ Output ตัวอย่างเช่น Wayu Paxa Edge v1.0.0 ระบุ 24,000 Hz และ Vachana Thai 22,050 Hz

**Auto:** Core ทดลองเปิดสตรีมด้วยอัตราของ WAV และค่าที่อุปกรณ์รองรับจริง หากต้องเปลี่ยน Sample Rate หรือ Mono/Stereo จะ Resample/แปลงช่องเสียงโดยรักษาเวลาและ Pitch เดิม ไม่แก้ไฟล์ WAV ต้นฉบับ

**กำหนดเอง:** Sample Rate และจำนวนช่องที่เลือกแบบตัวเลขคือ **ค่าบังคับ** Core ต้องเปิดสตรีมด้วยค่าที่เลือก หาก WAV ต้นทางต่างกันให้ Resample **เข้าค่าบังคับ** โดยไม่ปรับค่าที่เลือกเอง ถ้าอุปกรณ์ไม่รองรับให้รายงานข้อผิดพลาด ไม่เปลี่ยนเป็น Auto โดยเงียบ ๆ

หากกำหนด Rate เอง แต่ตั้งช่องเสียงเป็น Auto ระบบมีสิทธิ์เลือกจำนวนช่องที่รองรับ (และกลับกัน); ค่าที่ระบุตัวเลขจะต้องไม่เปลี่ยน ส่วน Buffer (ms) เป็นขนาดแบ่งส่ง ไม่ใช่อัตราสุ่มสัญญาณ

**ความปลอดภัย:** ถ้าไลบรารี `sounddevice` ไม่พร้อม ตัวสำรอง WinMM ไม่สามารถรับประกัน Sample Rate และ Channels ที่บังคับได้ จึงแจ้งข้อผิดพลาดสำหรับค่าที่บังคับ แทนการเล่นด้วยค่าอื่นโดยไม่บอก

**ข้อมูลสถานะ:** หน้าเว็บแสดงค่า Output ที่เลือก, WAV Sample Rate ของงานเสียงล่าสุด และ Sample Rate / Channels ที่อุปกรณ์ใช้เล่นจริง; เมื่อเปลี่ยนค่า Audio/Output จะยังไม่อ้างว่าได้เล่นด้วยรูปแบบใหม่จนกว่าเสียงถัดไปจะทำงานสำเร็จ ไม่ใช้รายงานจากครั้งเก่า

การเปลี่ยน Sample Rate **ไม่ทำให้เสียงที่โมเดลสร้างมาดีขึ้นโดยอัตโนมัติ** และการ Upsample 24,000 → 192,000 Hz ไม่ได้เพิ่มรายละเอียดเสียงต้นทางจริง

## Wayu Paxa Edge สำหรับภาษาไทย

แพ็กเกจ **[NC / NonCommercial] Wayu Paxa Edge v1.0.0** จากเครื่องผู้ใช้มี 12 เสียงและรองรับไทย/อังกฤษ เป็น Universal v4 ขนาดโมเดลประมาณ 327 MB ตัว Core ยืนยันว่า Runtime พร้อมใช้งานแล้ว

เมื่อติดตั้งโมเดลใหม่ รายการโมเดลในหน้าเว็บจะรีโหลด และเมื่อภาษาไทย (`th`) มีการกำหนดค่าไว้แล้ว ให้คลิก **แก้ไขโมเดล / เสียง** ในรายการภาษาไทยโดยตรง ไม่ต้องลบภาษาเดิมเพื่อให้กลับไปอยู่ช่อง "เพิ่มภาษา" เลือก Wayu และเสียงที่ต้องการ จากนั้นกดกำหนดโมเดลและบันทึก

การกำหนดค่า **Default Engine / Model ของโหมด** และ **โมเดล/Speed/DSP ตามภาษา** เป็นคนละชุด การตั้งค่าในโหมดที่เปิด "ใช้การเลือกโมเดลตามภาษา" หรือ "แยกอ่านข้อความตามภาษา" สามารถใช้ค่าตามภาษาทับค่า Default ของโหมดได้ หากเปลี่ยน Default แล้วเสียงไม่เปลี่ยน ให้ตรวจช่องนี้ก่อน

ค่าปรับ Speed เป็นคำสั่งให้โมเดลสร้างเสียง; ส่วน Gain/Pitch/Bass/Treble เป็นการปรับเสียง **หลังสร้าง WAV (DSP)** ซึ่ง Pitch ต้องอาศัย FFmpeg ที่มีตัวกรอง Rubberband ค่าใหม่มีผลกับงานที่รับเข้าใหม่เท่านั้น งานที่อยู่ในคิวหรือกำลังเล่นยังใช้ค่าที่บันทึกตอนสร้างงาน ไม่ได้เปลี่ยนย้อนหลัง

### การตรวจสอบ

- `tests/language_routes_ui_smoke.cjs` ตรวจการแก้ `th` หลังรีเฟรช, เปลี่ยน Wayu v4/เสียง, บันทึกค่าปรับ
- `tests/test_audio_devices_config.py` ตรวจ Auto 24 kHz → 192 kHz Stereo, กำหนดเอง 192 kHz ต้องใช้ 192 kHz, กำหนดเอง 24 kHz ที่อุปกรณ์ปฏิเสธต้องแจ้งผิดพลาด และไม่มี `sounddevice` ต้องไม่แอบใช้ WinMM
- `tests/test_audio_output_settings_truth.py` ตรวจรายงาน Actual Format หลังเปลี่ยนอุปกรณ์หรือ Audio Settings

ยังไม่ได้ยืนยันผลคุณภาพเสียงด้วยการฟังจริงจาก LIVE หรืออุปกรณ์ของผู้ใช้ จึงไม่อ้างว่าปัญหาเสียงทุกลักษณะถูกแก้แล้ว
