# VoxWeaveTTS v0.12.9 — ตั้ง IP/พอร์ต และแก้ Export JSON

## ดาวน์โหลดและติดตั้ง

1. ดาวน์โหลด `VoxWeaveTTS-v0.12.9-portable.zip` จาก Assets แล้วแตกไฟล์ เปิด `VoxWeaveTTS.exe` เพื่อเริ่มใช้งาน
2. [ดาวน์โหลดแพ็กเกจโมเดล `.vwmodel` v4](https://github.com/funggier/VoxWeaveTTS/releases/tag/v0.12.1-modelpacks-v4) แล้วเลือกติดตั้งจากเมนูจัดการโมเดลในโปรแกรม ใช้แพ็กเกจ v4 เดิมได้ โมเดลทั้ง 7 แพ็กเกจดาวน์โหลดแยกตามสัญญาอนุญาตของแต่ละแพ็กเกจ
3. ตรวจ SHA-256 ของ ZIP กับ `SHA256SUMS-v0.12.9.txt` ได้จาก Assets

## ตั้งค่าเครือข่าย

ใน Launcher เลือกเครือข่าย ใส่ **IPv4 address** กับ **Port** แล้วกด **Apply & Restart** โปรแกรมบันทึกค่าไว้ใน `data/network.json`

| โหมด | IP ที่โปรแกรมรับการเชื่อมต่อ |
| --- | --- |
| Local | `127.0.0.1` ใช้จากเครื่องที่รันโปรแกรม ค่าเริ่มต้นใช้พอร์ต `8765` |
| LAN | IPv4 ของอะแดปเตอร์ Ethernet หรือ Wi-Fi ที่เลือก |
| Tailnet | IPv4 ของอะแดปเตอร์ Tailscale ที่เลือก |
| All IPv4 | `0.0.0.0` รับการเชื่อมต่อจากทุกอะแดปเตอร์ IPv4 |

จากเครื่องอื่น เปิด `http://IP:พอร์ต/` โดยใช้ IP จริงของเครื่องเซิร์ฟเวอร์ เข้าด้วยชื่อผู้ใช้ `voxweave` กับรหัสในช่อง **Network login** ของ Launcher

```bat
Start-Console.cmd --host 127.0.0.1 --port 8775
```

`Start-Console.cmd` มีตัวอย่างคำสั่งแบบคอมเมนต์สำหรับทั้งสี่โหมด เปิดโดยไม่มีอาร์กิวเมนต์เพื่อใช้ค่าที่บันทึกไว้ หรือส่ง `--host` และ `--port` เพื่อเปลี่ยนค่าเฉพาะการเปิดรอบนั้น หากเปิดรับการเชื่อมต่อจากเครื่องอื่นก่อนเคยตั้งรหัสผ่าน ให้ตั้ง `VOXWEAVETTS_NETWORK_PASSWORD` ตาม [คู่มือเครือข่าย](https://github.com/funggier/VoxWeaveTTS/blob/v0.12.9/docs/NETWORK_TH.md)

## Export / Save As (.json)

บันทึกค่าคิวสุ่มและโปรไฟล์ YouTube/TikTok Browser ได้ จากหน้าเว็บบน LAN หรือ Tailnet เบราว์เซอร์จะรับไฟล์ JSON ไปบันทึกบนอุปกรณ์ที่เปิดหน้าเว็บ ไฟล์โปรไฟล์อาจมีข้อมูลรับรองของแหล่งข้อความ

## ขอบเขตการทดสอบ

ตรวจการเปิดทั้งสี่โหมด การบันทึก IPv4/พอร์ต และการเปิดผ่าน IPv4 ของอะแดปเตอร์ Tailscale บน Windows เครื่องทดสอบ ตรวจการยืนยันตัวตนของผู้ใช้จากเครือข่ายด้วยชุดทดสอบ HTTP การเชื่อมต่อจากอุปกรณ์ Tailnet เครื่องที่สองยังไม่ได้ทดสอบ
