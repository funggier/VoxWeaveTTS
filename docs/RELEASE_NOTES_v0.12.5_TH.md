# VoxWeaveTTS v0.12.5 — แยกกฎก่อนและหลัง AI

- ในหน้า **กฎการอ่านส่วนกลาง** เพิ่มระยะใต้ปุ่ม «โหลดค่าที่บันทึก» และแยกช่อง JSON เป็น **ก่อน AI** (`pre_ai`) และ **หลัง AI** (`post_ai`)
- แต่ละช่วงจัดรูปแบบ ตรวจ นำเข้า และดาวน์โหลด JSON ได้เอง ใช้ชื่อไฟล์ `rules-pre-ai.json` และ `rules-post-ai.json` เมื่อนำเข้าไฟล์เดิมที่รวมสองช่วง ระบบเลือกเฉพาะกฎของช่องที่กดนำเข้า
- ปุ่ม **บันทึกกฎทั้งสองช่วงในโปรแกรม** ใช้ไฟล์ตั้งค่าเดิม `data/filters/rules.json` กฎที่ไม่มี `stage` ในไฟล์เดิมแสดงในช่วงหลัง AI ลำดับกฎภายในแต่ละช่วงคงเดิม
- การเพิ่มกฎอย่างรวดเร็วจะเพิ่มลงในช่องตามช่วงที่เลือก
- ลดการตรวจแพ็กเกจ V4 ซ้ำเมื่อบันทึกโมเดลเสียงตามภาษา โหลด Voice Preset และสร้างเสียงในงานหลายภาษา

## ติดตั้งและอัปเดต

แตก `VoxWeaveTTS-v0.12.5-portable.zip` แล้วเปิด `VoxWeaveTTS.exe` หากอัปเดตจากรุ่นก่อน ให้ปิดโปรแกรมเดิมและย้ายโฟลเดอร์ข้อมูลการตั้งค่า พรีเซ็ต และโมเดลที่ต้องการใช้ต่อเข้าสู่โฟลเดอร์ใหม่

แพ็กเกจเสียงใช้ [ไฟล์ Universal V4 ที่เผยแพร่ไว้](https://github.com/funggier/VoxWeaveTTS/releases/tag/v0.12.1-modelpacks-v4) ได้ ส่วน TikTok Extension v0.2.6 และ Windows SAPI Desktop ใช้ชุดที่เผยแพร่ใน [v0.12.4](https://github.com/funggier/VoxWeaveTTS/releases/tag/v0.12.4) ได้ ตรวจไฟล์ Portable กับ `SHA256SUMS-v0.12.5.txt`
