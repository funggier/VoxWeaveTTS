# TikTok LIVE Reader ผ่าน TikFinity — VoxWeaveTTS v0.4.1

## ภาพรวม

TikTok ยังไม่มี **Public API ทั่วไป** ที่เปิดให้นักพัฒนาภายนอกอ่านข้อความไลฟ์สดโดยตรงอย่างเป็นทางการแบบ YouTube LIVE ดังนั้น VoxWeaveTTS ใช้ **TikFinity Desktop Event API** เป็นทางเชื่อมในเครื่อง ซึ่ง TikFinity ระบุว่ารองรับ `ws://localhost:21213/` บนคอมพิวเตอร์เดียวกัน

- เว็บ TikFinity: https://tikfinity.zerody.one/
- ข้อมูล Event API: https://tikfinity.zerody.one/tiktok/chatbot (ส่วน Event API)
- TikFinity เป็นซอฟต์แวร์ของบุคคลที่สาม ไม่ใช่ส่วนหนึ่งของ VoxWeaveTTS; อาจมีข้อกำหนด บัญชี ค่าใช้จ่าย หรือข้อจำกัดที่เปลี่ยนได้
- การเชื่อมต่อ TikTok ของ TikFinity **ไม่ใช่ Official TikTok LIVE API**; โปรดตรวจข้อกำหนดของ TikTok และ TikFinity ก่อนใช้งาน
- ไม่ต้องกรอกรหัสผ่าน TikTok หรือ Session Cookie ลงใน VoxWeaveTTS และไม่ติดตั้งเครื่องมือดึงข้อมูล TikTok ที่ทำ Reverse Engineering ภายในแพ็กเกจ

## ขั้นตอนเริ่มใช้งาน

1. เริ่มไลฟ์บน TikTok ด้วยบัญชีที่มีสิทธิ์ถ่ายทอดสด
2. ติดตั้งและเปิด **TikFinity Desktop** บนเครื่อง Windows เดียวกับ VoxWeaveTTS และให้ TikFinity เชื่อมเข้ากับไลฟ์ของคุณตามวิธีของ TikFinity
3. เปิด **TikFinity Event API / Local WebSocket** หากมีตัวเลือกเปิดใช้งาน (ชื่อเมนูอาจต่างตามเวอร์ชัน) และตรวจว่าระบบใช้ `ws://localhost:21213/`
4. เปิด VoxWeaveTTS ด้วย `VoxWeaveTTS.exe` แล้วเข้าแท็บ **TikTok LIVE**
5. ตรวจช่อง **Local WebSocket ของ TikFinity** ว่าเป็น `ws://localhost:21213/`; ตั้งค่าคำกรอง ความยาวข้อความ การอ่านอัตโนมัติ และจำนวนประวัติ
6. กด **เชื่อม TikFinity** เมื่อขึ้น `TikFinity: connected` แปลว่าเชื่อม Local WebSocket ได้แล้ว **ยังไม่ใช่หลักฐานว่า TikTok LIVE กำลังส่งคอมเมนต์** ให้ลองพิมพ์คอมเมนต์ใหม่ขณะไลฟ์และดูรายการข้อความที่เข้ามา
7. กด **หยุดรับข้อความ** หรือเปลี่ยนไปแท็บอื่นเพื่อหยุดรับและยกเลิกคิวเสียงของโหมดนี้

หากเปิด TikFinity หลัง VoxWeaveTTS อยู่แล้ว ให้กดเชื่อมใหม่เองหลัง TikFinity พร้อม ระบบตั้งใจไม่เริ่มเชื่อมอัตโนมัติเมื่อเปิดโปรแกรมหรือ Import โปรไฟล์

## ระบบข้อความและเสียง

- รับเฉพาะ Event `{"event":"chat","data":{"comment":"..."}}` ของ TikFinity: คอมเมนต์และผู้เขียน
- ไม่อ่านของขวัญ, ไลก์, การ Follow, การเข้าชม หรือ Event ประเภทอื่นโดยอัตโนมัติ
- กันข้อความซ้ำด้วย Message ID เมื่อผู้ให้บริการส่งมา จำกัดข้อมูลที่รับต่อ Event ปฏิเสธ URL/คำสั่งแชท และกรองคำตามที่ตั้งไว้
- ใช้คิวเสียงกลางเดียวกับ Live และ Discord: อ่านทีละข้อความ คิวรอสูงสุด 12 ข้อความ ข้ามข้อความใหม่ที่ล้นแต่ไม่ทิ้งข้อความเก่าที่ยังรออยู่
- เก็บประวัติข้อความที่อ่านแล้วเริ่มต้น 20 รายการ ปรับได้ 0–100 รายการ และไม่ลบข้อความที่ยังไม่อ่าน
- ใช้ Engine, Voice, กฎคำอ่าน และ OBS Subtitle ร่วมกับโหมดอื่น โดยมีเจ้าของเสียงได้เพียงโหมดเดียวในเวลาเดียวกัน
- สามารถเลือกข้อความบนหน้าจอเพื่ออ่านเอง หรือพิมพ์ข้อความทดลองได้แม้ไม่เปิด TikFinity

## Export / Import ตั้งค่า

- Export / Save As: เลือกชื่อไฟล์และตำแหน่งจาก Firefox หรือ Chrome
- Export จะรวมที่อยู่ Local WebSocket, คำกรอง, ความยาวข้อความ, เปิด/ปิดอ่านอัตโนมัติ และจำนวนประวัติ
- ช่องที่ยังไม่ได้กรอกสามารถเว้นว่างได้ เมื่อ Import ก็ยังคงว่างเช่นเดิม และต้องกดเชื่อมต่อเอง
- ไฟล์โปรไฟล์ TikTok ไม่มี Password/Token เพราะแอปไม่รับข้อมูลดังกล่าว แต่หาก Import โปรไฟล์ช่องอื่นซึ่งมี Token ให้เก็บไฟล์อย่างปลอดภัย

## ตรวจสอบปัญหา

| อาการ | ตรวจสอบ |
|---|---|
| เชื่อมไม่สำเร็จ | TikFinity Desktop ทำงานบนเครื่องเดียวกันและเปิด Local Event API แล้วหรือไม่ |
| เชื่อมสำเร็จแต่ไม่มีข้อความ | TikFinity เชื่อมกับ LIVE อยู่จริงหรือไม่ ลองส่งคอมเมนต์ใหม่หลังเชื่อม |
| มีรายการแต่ไม่พูด | ตรวจ Engine ที่พร้อม, Auto-read, สิทธิ์ Autoplay ของ Firefox/Chrome และคิวเสียง |
| หยุดอ่านเมื่อเปลี่ยนแท็บ | เป็นพฤติกรรมตั้งใจ เพื่อไม่ให้เสียงจากสองช่องทางซ้อนกัน |
| โปรไฟล์ Import แล้วไม่เชื่อม | เป็นพฤติกรรมตั้งใจ ต้องกด **เชื่อม TikFinity** เอง |
| อยู่คนละเครื่อง | เวอร์ชันนี้รองรับเฉพาะ TikFinity และ VoxWeaveTTS ที่เปิดบนเครื่องเดียวกัน |

## สถานะทดสอบ

มีชุดทดสอบจำลอง Event WebSocket, คิวเสียง, ตัวกรอง, Profile Export/Import, Stop/Disconnect และความปลอดภัยของ URL แล้ว แต่เครื่องที่สร้างรุ่นนี้ไม่มี TikFinity ที่เปิด Local WebSocket บนพอร์ต 21213 ขณะทดสอบ จึง **ยังไม่ได้ยืนยันกับ LIVE จริง** ต้องให้ผู้ใช้ทดสอบกับบัญชีของตนเองและ TikFinity Desktop

โมเดล/ไลบรารี TikFinity หรือไลบรารี TikTok ที่ไม่เป็นทางการไม่ได้ถูกบันเดิลใน VoxWeaveTTS Portable Release นี้
