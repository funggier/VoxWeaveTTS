นำเข้าเอกสาร TXT / Markdown (Engine-independent)

เลือกไฟล์ข้อความจากเครื่องคุณเพื่อจัดบท/ตอนและแบ่งช่วงอ่านข้อความโดยอัตโนมัติ ไม่ต้องใช้ Engine ในขั้นเตรียมเอกสาร ไฟล์จะอยู่ในหน่วยความจำของหน้านี้เท่านั้น ไม่บันทึกบนเซิร์ฟเวอร์ และไม่ส่งไป Cloud

ยังไม่ได้เปิดเอกสาร · UTF-8 หรือ Thai Windows-874 สูงสุด 300,000 ตัวอักษร (ข้อมูล request ไม่เกิน 1.25 MB)

เมื่อเปิดไฟล์ ระบบจะตรวจตำแหน่งที่เคยบันทึกไว้ โดยไม่เก็บเนื้อหาเอกสารลงดิสก์

ระบบจะเตรียมเสียงทีละช่วงเท่านั้น ไม่สร้างเสียงล่วงหน้าทั้งเล่ม · หาก Browser บล็อก Auto-play ให้กดปุ่มเล่นในแถบเสียง

Markdown จะไม่นำ Markdown Syntax, Code Fences, รูปภาพ และ URL จากลิงก์มาอ่าน · เวลาที่เห็นในระบบคิวยังเป็นระยะเวลาที่สร้างเสียง ไม่ใช่ Playback Clock จริง

สร้างเสียงภาษาไทย (M1 · CPU)

สร้าง WAV ภาษาไทยจริงจากข้อความด้านบน โดยใช้ Engine และเสียงผู้พูดที่เลือกไว้ด้านล่าง รวมถึง Rules/Pronunciations ที่กำหนด · ยังไม่มี Voice Cloning หรือการฝึกเสียงจากผู้ใช้

แต่ละ Engine อาจออกเสียงคำสั้นอย่าง “ฮ่า” ได้ต่างกัน การเปลี่ยน Seed ไม่ใช่การแก้การออกเสียงที่เชื่อถือได้ หากอ่านผิดสามารถปรับ Rules/Pronunciations ในส่วนข้อความด้านบนได้โดยตรง
